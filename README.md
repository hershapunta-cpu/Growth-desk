# ReBoRn Growth Desk

Prospect pipeline, scorecard, revenue planner, outreach drafts and 90-day roadmap for ReBoRn Marketing Solution Agency.

## Publish on GitHub Pages
1. Create a new public repository (for example `growth-desk`).
2. Upload every file in this folder, keeping the `icons` folder. Commit to the `main` branch.
3. Open Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Install on a phone
Open the link in Chrome (Android) or Safari (iPhone) and choose Add to Home Screen.

## Notes
- Data saves in the browser of each device only.
- The repository is public, so the files are visible to anyone. They include the business phone number used in outreach drafts, and the starter prospect list (public directory listings, unverified).
- Starter prospects are listings, not verified leads. Verify each one on a second source before contacting anyone.
